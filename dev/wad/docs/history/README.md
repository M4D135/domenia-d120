# Archives techniques historiques

Ces rapports, anciens lanceurs et anciens tests décrivent les révisions ADCC antérieures. Ils sont conservés pour étude et comparaison, pas annoncés comme validés pour Domenia RC1. Les noms du code dans certaines anciennes suites ont été adaptés pendant le renommage ; les fixtures et baselines sont historiques. Ne pas exécuter les anciens lanceurs déplacés : leurs chemins relatifs visaient leur ancienne racine.

Le point d’entrée de recette actuel est `TESTER-DOMENIA.cmd` à la racine DEV. L’audit portable courant est `tools/audit_candidate.py`. Les contrôles runtime de PROD ne dépendent pas de ce dossier.
