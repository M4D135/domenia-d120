# RC1.17.18 — fenêtre et préférences de sauvegarde

La taille et la position normales sont restaurées avant la maximisation. Enregistrer depuis une fenêtre maximisée utilise `RestoreBounds` ; réduire conserve le dernier choix normal/maximisé. Déplacement, redimensionnement et changement d'état mettent les préférences à jour via le writer différé existant ; la fermeture conserve l'écriture immédiate. Une position hors du bureau virtuel actuel revient dans la zone de travail principale.

La politique de sauvegarde et les reçus par base sont aussi ajoutés à la liste fermée des préférences conservées au rechargement. Cinq cas Windows 5.1 vérifient le vrai circuit Save/Load sur fichier JSON temporaire : activation, désactivation, dates/reçus de deux bases, rejet des clés/types invalides et limites de taille/nombre. Les trois premiers reproduisent le défaut sur RC17. Le contrôle d’admission bornée échoue également sur RC17 parce que les nouvelles clés y sont toutes rejetées ; le rejet des clés/types invalides y passe. Les cinq cas passent sur RC18. Aucun nouveau cycle applicatif complet RC18 n’est revendiqué.

Sept cas passent sous Windows PowerShell 5.1 STA avec de vraies fenêtres WPF, les deux fonctions et les trois gestionnaires d'événements extraits du Core livré : taille/position et JSON, maximisation et rectangle normal, réouverture maximisée puis rétablissement, fermeture réduite, position hors écran, valeurs initiales et garde de restauration. Les préférences du test sont isolées ; aucun appel réseau. Le Core complet est également analysé par le parseur Windows 5.1. Rapport : `WindowGeometry.json`.

`Qualification.json` lie le SHA-256 du Core testé au contenu des deux nouvelles archives ; `build-report.json` contient les contrôles statiques et d'intégrité. Cette vérification ciblée ne qualifie pas tous les parcours applicatifs de RC18. Les essais réels de stockage de la session précédente portent sur RC17 et restent dans [leur preuve](../rc17-storage-ui/README.md). Aucun test de topologie multi-écran physique ou de mélange de DPI n'est revendiqué. Décisions externes 134/146 et qualification générale ouvertes.
