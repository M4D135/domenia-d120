## 4. Règles techniques qui ont coûté cher (à appliquer sans exception)

Cible **Windows PowerShell 5.1 x64 STA** uniquement (voir `CLAUDE.md` pour la liste des syntaxes interdites).
Pièges rencontrés sur ce chantier :
- `$null` passé à un paramètre .NET `[string]` devient `""` : utiliser `[NullString]::Value` (cas de `File.Replace`).
- `@($null).Count -eq 1`.
- Un `switch` à cas chaîne compare selon la culture (U+00AD a été jugé égal à "`0").
- **Dans un appel de méthode, la virgule sépare les arguments** : `$list.Add($x -replace 'a','b')` passe DEUX arguments.
  Calcule d'abord dans une variable. (Ce défaut a été écrit par un modèle et attrapé par un test ; il aurait cassé la
  confirmation de suppression.)
- `IADsLargeInteger` se lit par IDispatch (`InvokeMember('HighPart'/'LowPart', GetProperty)`).
- `-and`/`-or` ont la même priorité : parenthéser.
- `.ContainsKey` n'existe pas sur un `OrderedDictionary` (`.Contains`). Pas de clés en double dans un littéral de hashtable.
- `DirectoryConnection` est abstraite : c'est `LdapConnection` ; l'énumération est `[System.DirectoryServices.Protocols.AuthType]`,
  `ProtocolVersion` est sur `SessionOptions`, et `SendRequest` renvoie une réponse à lire (un *referral* ne lève pas d'exception).
- Ne jamais découper une identité UPN (`user@suffixe`) en utilisateur + domaine pour une connexion : seul `DOMAINE\user` se découpe.
- Encodage : `.ps1` en UTF-8 **avec BOM**, fins de ligne LF. Convention de ce chantier (non écrite dans `CLAUDE.md`) :
  le texte **ajouté** dans `Domenia-Core.ps1` et dans les workers est en ASCII sans accents ; ne convertis pas les
  textes accentués existants. Apostrophe typographique `ʼ` (U+02BC) seulement là où le module l'utilise déjà.

Leçons de harnais de test (suites `wad/tests/*.ps1`) :
- Importer les fonctions **au niveau du script**, pas dans une fonction (une fonction dot-sourcée dans une fonction disparaît).
- Les doublures vues par un minuteur ou un rappel se définissent par `Set-Item function:script:NOM`.
- Un espion capture `(Get-Command X).ScriptBlock` avant remplacement.
- Mettre entre parenthèses les arguments calculés (`-State ([pscustomobject]@{...})`).
- Un harnais qui charge un module UI doit charger les règles (`*.Model.ps1`) dont il dépend.
- Le code commun des workers est réparti en plusieurs blocs `$script:WorkerCommon += @'...'@` : une suite qui ne charge
  que le premier bloc ne voit pas les fonctions ajoutées ensuite (charger le bloc voulu depuis l'AST de Core).
- Une doublure trop large masque un défaut (cas D024 : le test doublait `ConvertTo-DomeniaLiveObservation` et cachait un
  rajeunissement réel). Quand c'est possible, prouver un test par **mutation** (casser le code, vérifier que le test échoue).
